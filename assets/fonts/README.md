# Fonts for share images

`next/og` (Satori) needs TTF/OTF files, so these are static instances of the
site's fonts, used only by `src/lib/og.tsx`. Both are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org).

- Bricolage Grotesque (ExtraBold, condensed, 96pt optical size), by Mathieu Triay
- Schibsted Grotesk (Medium, Bold), by Schibsted Media Group

Downloaded from Google Fonts.
